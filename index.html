База тестовых изображений

Все изображения генерируются программно по запросу и также доступны для загрузки в формате PNG. Их можно загрузить в рабочую область и обработать любым методом.

Браузер может запросить разрешение на скачивание нескольких файлов.

Архитектура (три слоя)

  • Presentation Layer — js/main.js, index.html, css/style.css: отображение «до/после», гистограммы, прогресс, слайдеры.
  • Memory & Pixel Access Layer — js/core/pixel.js: обёртка над байтами изображения (Uint8ClampedArray), обработка краёв (Clamp / Reflect), преобразования RGB↔HSV.
  • Processing Layer — js/algo/*.js: чистые функции-алгоритмы, не знающие об интерфейсе.

Обнаружение точек

Лапласиан 3×3: маска −1 в 8 соседях и 8 в центре. Изолированная точка даёт отклик |R| = |8f₀ − Σfсосед|, который заметно превышает фон. Порог T бинаризует отклик.

Обнаружение линий

Четыре маски лапласиана, ориентированные на 0°, 45°, 90°, 135°. Отклик — максимум по четырём свёрткам; номер маски-победителя задаёт цвет обнаруженной линии на карте.

Перепады яркости: Соболь/Прюитт/Робертс

Вычисляются частные производные gx, gy свёрткой с масками; модуль градиента M = √(gx² + gy²), угол направления θ = atan2(gy, gx). Карта направлений кодирует угол цветовым оттенком (HSV: hue = θ), а яркость — модулем градиента.

Алгоритм Кэнни

1) разделяемая гауссова свёртка; 2) градиенты Соболя; 3) подавление немаксимумов вдоль направления градиента (опционально — субпиксельное, с билинейной выборкой); 4) двойная пороговая обработка и гистерезис (рост связных компонент от сильных границ через слабые).

Гистограммы и контраст

Линейное контрастирование: g′ = (g − a)·255/(b − a). Эквализация: g′ = round((CDF(g) − CDFmin)/(N − CDFmin)·255). Для цветных изображений реализованы два подхода: поканальная эквализация RGB и эквализация только компоненты V в HSV. CLAHE — эквализация по сетке областей с ограничением гистограммы (clip limit) и билинейной интерполяцией отображений соседних областей.

Оптимизации

  • Разделяемые свёртки: O(K²·N²) → O(K·N²) (два одномерных прохода).
  • Многопоточность: пул Web Workers, изображение делится на горизонтальные полосы.
  • Прямой доступ к памяти: только Uint8ClampedArray/Float32Array и вложенные циклы, никаких высокоуровневых функций обработки.
