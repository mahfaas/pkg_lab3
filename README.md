# Обработка цифровых изображений — Лабораторная работа 3

**Вариант 4:** сегментация изображений (обнаружение точек, линий и перепадов яркости) + построение и эквализация гистограммы изображения с линейным контрастированием.

Веб-приложение на чистом HTML/CSS/JavaScript без внешних зависимостей. Все алгоритмы обработки изображений написаны с нуля: прямой побайтовый доступ к пиксельным буферам (`Uint8ClampedArray` / `Float32Array`), только вложенные циклы, никаких библиотечных функций обработки изображений.

**Демонстрация (GitHub Pages):** `<ссылка будет добавлена после публикации>`

## Запуск

Приложение — статический сайт, требуется только веб-сервер (для работы Web Workers открытие по `file://` не подходит; при их недоступности приложение автоматически переходит в однопоточный режим).

```bash
# вариант 1: любой статический сервер
python -m http.server 8000
# вариант 2: node
npx serve .
```

Затем открыть `http://localhost:8000`. Сборка не требуется.

Смоук-тесты алгоритмического ядра (21 проверка: краевые стратегии, разделяемые свёртки, полосная обработка, операторы градиента, LUT гистограмм, цветовые преобразования):

```bash
npm test
```

Генерация протокола испытаний и отчёта (изображения результатов, измерения контрольных пикселей, сборка docx):

```bash
node tools/gen_report.mjs
python tools/make_report.py
```

## Состав работы по варианту

### 1. Сегментация: точки, линии, перепады яркости

| Метод | Реализация |
|---|---|
| Обнаружение точек | Лапласиан 3×3 (8 соседей), пороговая бинаризация отклика |
| Обнаружение линий | 4 ориентированные маски лапласиана (0°, 45°, 90°, 135°), выбор максимума отклика, цветовая маркировка ориентации |
| Перепады яркости | Операторы Робертса, Прюитта, Соболя: модуль и угол градиента для каждого пикселя |
| Алгоритм Кэнни | Гауссово сглаживание (разделяемая свёртка) → градиенты Соболя → подавление немаксимумов вдоль направления градиента (классическое и **субпиксельное** с билинейной выборкой) → двойная пороговая обработка + гистерезис |
| Карта направлений | Честный угол θ = atan2(g_y, g_x) для каждого пикселя; визуализация цветом (HSV: тон = угол, яркость = модуль градиента) |

### 2. Гистограммы и контрастирование

| Метод | Реализация |
|---|---|
| Линейное контрастирование | g′ = (g − a)·255/(b − a); авто-режим по min/max либо ручные a, b |
| Эквализация гистограммы | g′ = round((CDF(g) − CDF_min)/(N − CDF_min)·255) |
| Эквализация цветного RGB | Независимое выравнивание гистограмм трёх цветовых компонент |
| Эквализация цветного HSV | Выравнивается только компонента яркости V, тон и насыщенность сохраняются |
| CLAHE | Адаптивная эквализация по сетке областей с ограничением контраста (clip limit, перераспределение избытка) и билинейной интерполяцией отображений соседних областей |

Приложение строит и отображает гистограммы **до и после** обработки (наложение каналов R/G/B) — сравнение подходов выполняется визуально прямо в интерфейсе.

## Техническая реализация и оптимизации

1. **Честный пиксельный доступ.** Изображение переводится в `Float32Array` яркостей (или обрабатывается прямо в RGBA-байтах) — «сырая» память без построчного GetPixel/SetPixel-доступа. Вся фильтрация — вложенные циклы. Canvas API используется только для ввода/вывода (декодирование файлов, отрисовка результата) и генерации тестовых сцен, но не для обработки.
2. **Обработка краёв.** Две стратегии на выбор в интерфейсе:
   - *Clamp (дублирование)* — выход за границу заменяется ближайшим граничным пикселем;
   - *Mirror (зеркальное отражение)* — индекс отражается относительно границы.
3. **Разделяемые свёртки.** Гауссово и бокс-сглаживание реализованы как два последовательных одномерных прохода (сначала по строкам, затем по столбцам): сложность O(K²·N²) → O(K·N²). Корректность проверена тестом (совпадение с полной 2D-свёрткой, maxDiff < 10⁻⁵).
4. **Карта направлений градиента.** Для операторов Соболя/Прюитта/Робертса и Кэнни вычисляется угол θ = atan2(g_y, g_x) в каждом пикселе и строится цветовая карта (тон кодирует угол, яркость — модуль).
5. **CLAHE** — адаптивная эквализация с ограничением контраста по областям и билинейной интерполяцией LUT соседних областей (уступает скользящему окну по строгости, но даёт O(N) на пиксель вместо O(K²·N²); реализация на компоненте V в HSV).
6. **Субпиксельный Кэнни.** Подавление немаксимумов выполняется сравнением с билинейно интерполированными значениями модуля градиента в точках ±(cos θ, sin θ) — максимум границы локализуется с субпиксельной точностью.
7. **Многопоточность.** Пул Web Workers (до 8 потоков, по числу ядер): изображение делится на горизонтальные полосы, каждая обрабатывается независимо; обмен — переносимыми типизированными массивами. При недоступности воркеров автоматический переход в однопоточный режим (в строке состояния отображается фактический режим и число потоков).

## База тестовых изображений

 Генерируется программно (512×512, детерминированно — сеяный ГПСЧ, растеризация без Canvas, результаты воспроизводимы) во вкладке «База тестовых изображений», каждое можно загрузить в рабочую область и скачать как PNG:

| Изображение | Назначение |
|---|---|
| Синтетическая сцена | Изолированные точки, линии четырёх ориентаций, контуры фигур — проверка всех детекторов |
| Малоконтрастная сцена (100–160) | Линейное контрастирование, эквализация |
| Гауссов шум (σ = 25) | Устойчивость детекторов, роль сглаживания в Кэнни |
| Импульсный шум «соль и перец» (5%) | Ложные отклики детектора точек |
| Размытие (бокс 7×7) | Ослабление границ, чувствительность порогов |
| Неравномерная засветка | Поведение методов при непостоянной яркости фона |
| Цветная малоконтрастная | Сравнение эквализации RGB и V в HSV |
| Градиент + текст | Узкая гистограмма: глобальная эквализация против CLAHE |

## Краткие пояснения методов

- **Точки.** Отклик лапласиана R = 8·f₀ − Σf_сосед максимален на изолированных точках; порог T выделяет их. На изображениях с шумом появляются ложные обнаружения — наглядно на «соль и перец».
- **Линии.** Каждая из четырёх масок настроена на свою ориентацию (положительные веса вдоль направления). Пиксель размечается ориентацией маски с максимальным |откликом|; в приложении ориентации различаются цветом.
- **Перепады.** Модуль градиента M = √(g_x² + g_y²) достигает максимума на перепадах; направление θ = atan2(g_y, g_x) перпендикулярно границе. Робертс (2×2) быстрее, но чувствительнее к шуму; Соболь с весами 1-2-1 даёт сглаживание вдоль границы.
- **Кэнни** оптимизирует три критерия: хорошее обнаружение, локализация, единственный отклик на границу — за счёт сглаживания, NMS и гистерезиса.
- **Эквализация RGB против HSV.** Поканальная эквализация RGB изменяет соотношения каналов → цветовые искажения; выравнивание только V сохраняет тон и насыщенность. Сравнение — на цветной малоконтрастной сцене.
- **CLAHE.** Ограничение гистограммы препятствует чрезмерному усилению шума и усилению контраста на фоне, интерполяция между областями устраняет блочные артефакты. В отличие от глобальной эквализации сохраняет общее распределение яркости.

Соответствие критериям оценки (9–10 баллов): честный побайтовый доступ, обработка краёв двумя стратегиями, разделяемые свёртки, субпиксельный Кэнни, CLAHE, карта направлений градиента, многопоточная обработка полос, база тестовых изображений, аналитический отчёт с анализом гистограмм до/после.
